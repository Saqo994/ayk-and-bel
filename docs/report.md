# Отчёт по автономному заданию

## Что готово

Игру можно пройти целиком: меню → заставка → Вавилон → заставка → Путь на север → заставка → Страна Арарат → заставка → Айоц-Дзор и бой с Белом → финальная заставка → титры.

Как запустить:

```
npm run dev
```

и открыть в Chrome адрес, который покажет команда (обычно http://localhost:5173).

Управление: стрелки или WASD — движение, пробел (или W, стрелка вверх) — прыжок, X — выстрел (держать до секунды — заряженный), Esc — пауза.

Что есть в игре:
- **Меню:** «Начать игру», «Продолжить» (с последнего открытого уровня), «Настройки» (громкость музыки и эффектов). Музыка меню включается после первого нажатия клавиши.
- **Айк:** бег с разгоном, прыжок с тремя «удобствами» (можно прыгнуть чуть сойдя с края, нажатие запоминается перед приземлением, короткое нажатие — короткий прыжок), лук с зарядом и полоской над героем.
- **Здоровье:** три сердца, секунда неуязвимости после удара, три чекпоинта на уровень, экран проигрыша с «Заново».
- **Монеты:** за каждые 50 монет даётся сердце (одно можно носить сверх трёх), счёт переносится между уровнями.
- **Враги:** копейщик (ходит, делает выпад), лучник (стоит, стреляет с заметной подготовкой), волк, кабан, медведь, мирный олень, ловушки-колья.
- **Уровень 1, Вавилон:** закат, пыль, факелы, башни с лучниками в конце.
- **Уровень 2, Путь на север:** порывы ветра (сносят в прыжке, перед порывом снег ускоряется), скользкий лёд, обваливающиеся плиты, снег.
- **Уровень 3, Страна Арарат:** светлый простор, ручьи вместо ям, звери, много монет.
- **Уровень 4, Айоц-Дзор:** дождь, молнии, плотные ряды копейщиков и лучников, затем арена с Белом.
- **Бел:** обычные стрелы отскакивают от щита, ранят только заряженные; рывок с мечом, удар по земле с волной, на половине здоровья зовёт двух копейщиков; три фазы, каждая быстрее; на последнем выстреле время замедляется и камера летит за стрелой.
- **Звук:** временный, собран кодом — шаги (камень, снег, трава, дерево, лёд), прыжок, тетива, попадания, монеты, фон каждого уровня.

## Как это проверялось

- `npm run shots` — скриншоты 21 сцены в `docs/screenshots/`, ошибок в консоли браузера нет. Все скриншоты я просмотрел.
- `npm run check` — расчёт по числам из `src/config.js`: на всех уровнях каждая платформа достижима прыжком (с запасом 15 %).
- `npm run bot` — бот в браузере пробежал уровни 1–4 от старта до конца (на уровне 4 — до арены) без единого падения, 60 кадров в секунду.
- Бой с Белом прогнан автоматически: урон, фазы, призыв копейщиков, проигрыш, победа и переход к финалу работают.
- Пройдена цепочка меню → настройки → заставка → уровень 1 → пауза.

Чего проверка **не** покрывает: бот бежит с включённой неуязвимостью, то есть проверяет прыжки, а не бой. Человек игру целиком не проходил, поэтому сложность врагов и Бела подобрана по расчёту, а не по ощущениям.

## Что упрощено или не получилось

- **Музыки на уровнях нет** — по заданию она не сочинялась, есть только фоновая атмосфера.
- **Все звуки, кроме музыки меню, — заглушки.** Звучат условно, их нужно заменить записями.
- **Лучник — перекрашенный копейщик.** Из-за цветокоррекции уровня синеватый оттенок почти не виден, лучника легче узнать по тому, что он стоит на месте и мигает жёлтым перед выстрелом.
- **Анимаций у врагов и Бела нет** — они покачиваются и наклоняются кодом.
- **Уровень 2:** среднего плана и платформ нет, взяты скалы Айоц-Дзора с синим оттенком, снег и лёд нарисованы кодом. `north-mid.png` (ущелье) не использован.
- **Уровень 3:** средний план — две плоские зелёные полосы, переднего плана нет. Яркие ассеты приглушены общим снижением насыщенности.
- **Земля на всех уровнях** собрана из одной картинки, повторённой в ряд, — видны стыки.
- **Чекпоинт, факелы, вода в ручьях, волна от удара Бела** нарисованы кодом.
- **Стиль выровнен только цветом:** Айк, звери, монеты и сердца приглушены кодом, но нарисованы они всё равно проще и «игровее», чем фоны. Настоящее единство даст только перерисовка.
- Коммиты объединяют по несколько этапов, а не по одному на этап.

## Известные ошибки и шероховатости

- Айк из ленты мелкий (кадры 200×196 растянуты в 1,3 раза) и слегка размыт.
- Если встать вплотную к Белу, он ранит касанием постоянно (с перерывом на секунду неуязвимости).
- Олень, добежав до края своей площадки, просто останавливается.
- В моём окружении команды `npm run …` не запускались (npm не находил node), поэтому я вызывал те же скрипты напрямую: `node node_modules/vite/bin/vite.js build`, `node scripts/shots.mjs`. В обычном терминале `npm run dev`, `build`, `shots`, `check`, `bot` должны работать, но это стоит проверить первым делом.

## Принятые решения

Полный список — в `docs/decisions.md`. Главные:
- Мир высотой в один экран, камера движется только по горизонтали.
- Падение в яму отнимает сердце и возвращает к чекпоинту; «Заново» после проигрыша — тоже с чекпоинта, с тремя сердцами.
- Заряженным считается только полностью натянутый выстрел (1 секунда).
- У Бела 9 заряженных попаданий (по 3 на фазу); верхние уступы арены обваливаются, чтобы наверху нельзя было отсидеться.
- Ветер на уровне 2 дует навстречу и действует только в прыжке — порыв можно переждать на земле.
- Рамки переднего плана увеличены в 1,5 раза: в исходном размере они закрывали героя.
- Фон меню собран из слоёв Арарата и портрета Айка, пока нет `menu-bg.jpg`.

## Что проверить руками в первую очередь

1. **Запуск:** `npm run dev` открывает меню, после нажатия клавиши играет музыка.
2. **Ощущение прыжка и бега** на тестовом уровне: адрес с добавкой `?level=0`. Если герой кажется тяжёлым или скользким — числа в `src/config.js` (раздел `PLAYER`).
3. **Бой с Белом:** адрес с `?level=4&cp=3`. Можно ли увернуться от рывка и волны, не слишком ли долго (9 попаданий), понятен ли сигнал перед атакой. Числа — в `src/config.js` (раздел `BOSS`).
4. **Ветер на уровне 2** (`?level=2`): заметно ли предупреждение перед порывом и честно ли он сносит.
5. **Сложность уровня 4** до арены (`?level=4`): копейщики и лучники стоят плотно.
6. **Тексты заставок** в `src/scenes/Story.js` — верно ли пересказана легенда.
7. **Звук:** не режут ли слух временные эффекты; громкость настраивается в меню.

Для быстрых проверок: `&debug=1` в адресе показывает хитбоксы, клавиши 1–4 переключают уровни, G включает неуязвимость.

## Чего не хватает из ассетов

Полный список по важности — в `docs/missing-assets.md`. Сильнее всего игру улучшат: анимация Айка в живописном стиле, отдельный лучник, анимации копейщика и Бела, музыка и настоящие звуки.
