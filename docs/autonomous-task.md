## Главные правила автономного режима

1. **Не останавливайся на вопросы.** Если сомневаешься — выбери более простой вариант, запиши решение одной строкой в `docs/decisions.md` и иди дальше. Правило из CLAUDE.md «покажи план и дождись ок» в этом задании не действует.
2. **Нет ассета — не стой.** Нарисуй заглушку кодом (или переиспользуй похожий ассет) и добавь строку в `docs/missing-assets.md`: что нужно, размер, формат, прозрачный ли фон, описание для генерации.
3. **После каждого этапа:** `npm run build` должен проходить без ошибок, затем git-коммит с понятным сообщением на русском и обновление раздела «Текущее состояние» в `CLAUDE.md`.
4. **Проверяй глазами.** Поставь Playwright и сделай скрипт `npm run shots`: он открывает игру, заходит в каждую сцену/уровень (через `?level=N`), ждёт пару секунд, сохраняет скриншот в `docs/screenshots/` и падает, если в консоли браузера есть ошибки. Запускай его после каждого этапа, **открывай скриншоты и смотри на них**: слои на месте, герой стоит на платформе, ничего не растянуто и не перекрыто. Нашёл проблему — исправь до перехода к следующему этапу.
5. **Сломалось — ищи причину**, не переписывай всё заново. Если один этап не получается после трёх серьёзных попыток — оставь рабочую упрощённую версию, запиши проблему в `docs/report.md` и переходи к следующему.
6. **Границы.** Работай только внутри этой папки. Ничего не удаляй из `public/assets/` и `docs/`. Не пушь в удалённые репозитории. Не скачивай чужую графику, музыку и звуки. Новые библиотеки — только Phaser 3, Vite и Playwright (для проверки).
7. Если не установлен Node.js или git — установи (winget) и продолжай.

## Что должно получиться

Законченная игра, которую можно пройти от меню до финала:
меню → заставка → уровень 1 (Вавилон) → заставка → уровень 2 (Путь на север) → заставка → уровень 3 (Страна Арарат) → заставка → уровень 4 (Айоц-Дзор) с боссом Белом → финальный экран.

## Этапы (по порядку)

### 0. Основа
Vite + Phaser 3, git init, `.gitignore`, структура из CLAUDE.md, базовое разрешение 1920×1080 со Scale.FIT. Загрузка ассетов по уровням (не всё сразу). Параметр `?level=N` и `?debug=1` (хитбоксы, клавиши 1–4 для перехода между уровнями, неуязвимость по клавише G).

### 1. Движение героя
Тестовый уровень на серых коробках. Бег с разгоном и торможением, прыжок с coyote time, jump buffering и переменной высотой, камера с плавным следованием. Все числа — в `src/config.js`. Управление: стрелки/WASD, пробел — прыжок, X — выстрел.

### 2. Айк
Спрайт и анимации из `public/assets/hayk/hayk-sheet.png` (раскладка кадров описана в CLAUDE.md): стойка, бег, прыжок, выстрел. Высота героя на экране около 200 px. Поворот — отражением по горизонтали. Хитбокс уже спрайта.

### 3. Лук
X — выстрел стрелой (`hayk/arrow.png`) в сторону взгляда. Удержание X до 1 с — заряженный выстрел: дальше, быстрее, больше урон; полоска заряда над героем. Стрела летит по дуге, втыкается в стены, исчезает через 2 с.

### 4. Здоровье, предметы, интерфейс
3 жизни-сердца, неуязвимость 1 с после удара, чекпоинты, возрождение, экран проигрыша с «Заново». Предметы из `public/assets/pickups/`: монеты (счёт), сердце (жизнь). Отдельная сцена интерфейса: сердца, счёт монет, название уровня при входе.

### 5. Враги
- Копейщик Бела (`enemies/spearman.png`): ходит по платформе туда-обратно, разворачивается у края, при виде героя делает выпад. 2 попадания стрелой или 1 заряженное.
- Лучник Бела: отдельного спрайта нет — используй копейщика с другим оттенком и запиши в missing-assets. Стоит на месте, стреляет с задержкой, стрелы врага видно заранее.
- Звери для уровня 3: волк (быстро бегает), кабан (разгоняется по прямой), медведь (медленный, много здоровья). Олень — мирный, убегает.
- Ловушки из `public/assets/hazards/`.
Анимаций у врагов нет — оживи кодом: покачивание, наклон при движении, вспышка при попадании, исчезновение при гибели.

### 6. Уровень 1 — Вавилон
Данные уровня в `src/levels/`. Длина 9–10 экранов, сложность растёт: начало — простые прыжки, середина — копейщики и ямы, конец — лучники на башнях. 3 чекпоинта. Параллакс: небо, дальний план, стена, передний план из `public/assets/babylon/`, платформы из `babylon/platforms/`, декорации из `babylon/props/` только на фоне. Атмосфера по CLAUDE.md: закатная подкраска, пыль в воздухе, мерцание факелов, виньетка.

### 7. Уровень 2 — Путь на север
Ассеты `public/assets/north/`. Готового среднего плана и платформ нет: для платформ возьми скальные уступы из `hayots-dzor/platforms/` с холодным синим оттенком и снежной шапкой, нарисованной кодом; запиши в missing-assets. Механика уровня: порывы ветра, которые сносят в прыжке (перед порывом — видимый сигнал: летящий снег ускоряется), скользкий лёд, обваливающиеся плиты. Снег частицами, холодная цветокоррекция.

### 8. Уровень 3 — Страна Арарат
Ассеты `public/assets/ararat/`: предпочитай `platforms/painted-*.png` и `ararat-far.png`; яркие ассеты используй только там, где другого нет, и приглуши их насыщенность кодом, чтобы не выбивались. Небо — градиентом. Спокойный, светлый уровень: больше простора и монет, враги — звери. Не использовать lamp-post, barrel, crate.

### 9. Уровень 4 — Айоц-Дзор и Бел
Ассеты `public/assets/hayots-dzor/`. Первая половина — прорыв через войско: копейщики и лучники плотнее, чем раньше, вспышки молний (кратко осветляют сцену), дождь. Вторая половина — арена с Белом (`enemies/bel.png`, высота около 300 px, полоса здоровья сверху экрана):
- Щит Бела отражает обычные стрелы спереди. Урон наносят только заряженные выстрелы.
- Атаки с заметной подготовкой: рывок с ударом меча; удар по земле с волной, которую надо перепрыгнуть; на половине здоровья призывает двух копейщиков.
- Три фазы, каждая быстрее предыдущей.
- Последний удар: время замедляется, камера следует за стрелой, затем финальная заставка.
Бой должен быть проходим: проверь, что все атаки можно избежать.

### 10. Меню, заставки, финал
- Главное меню: `menu-bg.jpg` ещё нет — собери фон из неба и слоёв Айоц-Дзора или Арарата; название игры «Айк и Бел» (временное); пункты «Начать игру», «Продолжить» (с последнего открытого уровня, localStorage в try/catch), «Настройки» (громкость музыки и эффектов).
- Музыка меню: `public/assets/menu/menu-theme.ogg/.mp3`, запуск после первого нажатия, плавное затухание при старте.
- Заставки между уровнями: чёрный экран, 1–2 предложения легенды своими словами (по Мовсесу Хоренаци, без изменения исхода), продолжение по любой клавише.
- Финальный экран и титры (источники ассетов из `CREDITS.md`: графика сгенерирована автором в Gemini, музыка меню предоставлена автором).
- Пауза по Esc.

### 11. Звук
Готовых звуков и музыки уровней нет. Сделай всё процедурно через WebAudio как временную замену и запиши каждый звук в missing-assets:
- эффекты: шаги (разные для камня, снега, травы), прыжок, приземление, тетива, попадание, удар, монета, гибель врага;
- эмбиент уровней: городской гул и далёкие барабаны (1), ветер (2), птицы и ручей (3), барабаны и гром (4);
- музыку уровней не сочиняй — только эмбиент; общий слой громкости и плавные переходы между сценами.

### 12. Полировка и проверка
- Пройди `npm run shots` по всем сценам, посмотри каждый скриншот, исправь найденное.
- Проверь каждый уровень на проходимость: каждый прыжок должен быть выполним при параметрах из `config.js` (напиши простой скрипт проверки расстояний между платформами или пройди уровень автоматическим тестом в Playwright).
- 60 FPS: не создавай объекты каждый кадр, используй пулы для стрел и частиц.
- Убери отладочный вывод, оставь `?debug=1`.
